# Anagrams Factory
Anagrams Factory generates anagrams and displays them, paginated (optionally, excluding duplicates).

## Prerequisites
- Node.js
- Docker

## Environment

### First run :hammer:

1 - From the folder `backend`:

```bash
  yarn
```

2 - From the project root:

```bash
  docker compose up --build
```

### Run :point_right:

From the project root:

```bash
  docker compose up
```

### Stop :hand:

From the project root:

```bash
  docker compose stop
```

## Development server
### App url
`http://localhost:8000/`
